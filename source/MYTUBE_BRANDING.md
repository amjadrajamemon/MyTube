# MyTube Branding

- Installed Android application label: **MyTube**
- Android Studio project name: **MyTube**
- Launcher icon: approved glossy red 3D M/play icon
- Standard and adaptive launcher icon resources are included.
- Default fresh-install download folder name: **MyTube**
- `compile_apk.bat` also creates a root-level copy named `MyTube-v1.1.1-debug.apk` after a successful build.

Internal Kotlin/Java package and namespace identifiers are intentionally unchanged to minimize compatibility risk.
